# KEYBOARD AWARE LoGIN SCREEN
A simple React Native login screen that demonstrates the use of **React-native-keyboard-aware-scroll-view** to handle keyboard appearance and ensure input fields and button remain visible.

# FEATURES
- Responsive layout by using KeyboardAwareScrollView.
- Two controlled TextInput fields for username and password.
- Button toggles between login and logout.
- Display login information.

# INSTALLATION

1. Clone Repository:

    ```bash
    git clone https://github.com/berna-ikiz/KeyboardAvoidingView.git
    ```

2. Install dependencies:

    ```bash
    yarn install
    ```

# RUN THE APP

- Run the app with this code

    ```bash
    npx expo start
    ```

- Press i to open in iOS Simulator (Mac only)

- Press a to open in Android Emulator

- Or scan the QR code with your Expo Go app on a real device
